System Architecture & ML Pipelines

Verifiable multi-stage architecture powering the AI-Text-and-Deepfake-Detection-Using-ML framework.

📝 Text Detection Pipeline (V2 Improved)

1
Text Input Preprocessing

Standardizes text, computes word/character counts, extracts basic sentence statistics.

2
Multi-Feature Generation
  • Word TF-IDF (150,000 features)
  • Character TF-IDF (150,000 features)
  • MiniLM L6 v2 Embeddings (384-dim)
  • Scaled Linguistic Features (5-dim)
3
Sparse Feature Fusion

Combines sparse & dense representations into a unified feature vector of 194,545 dimensions.

4
Logistic Regression Classification

Evaluates prediction probability against saved decision threshold (0.41) to output HUMAN-WRITTEN or AI-GENERATED verdict.

🎥 Video Deepfake Pipeline

1
OpenCV Uniform Frame Extraction

Extracts 8 uniform frames across video duration, resizes to 224×224 RGB tensors.

2
Spatial Feature Extraction (ResNet-18)

Pretrained ResNet-18 extracts 512-dimensional spatial feature representations per frame.

3
Temporal Attention Network

2-layer Bidirectional LSTM models temporal frame-to-frame transitions while a soft attention head weights critical temporal frames.

4
Deepfake Classification

Linear classifier head outputs real probability (Threshold: 0.50). Mapping: 0 = Fake, 1 = Real.
