PIPELINE SPECIFICATIONS

MODEL ARCHITECTURE

Detailed architecture and forensic inference pipelines powering the platform.

📄

TEXT DETECTION PIPELINE (FROZEN V3.4)

Sparse TF-IDF + Dense MiniLM Semantic Fusion (194,897 Total Dimensions)
1
Input Preprocessing & Length Gating

Sanitizes UTF-8 tokens, computes word/character telemetry. Gating rule: 1–2 words classified as INSUFFICIENT_EVIDENCE.

2
Multi-Scale TF-IDF Feature Extraction

Generates Word n-grams (1–3), Char n-grams (3–5), and Subword n-grams (2–6), extracting over 194,500 sparse dimensions.

3
Dense MiniLM Embeddings & Stylistics

Extracts 384-dimensional dense semantic representations via MiniLM-L6-v2 plus 5 scaled stylistic dimensions (entropy, sentence length, vocabulary diversity).

4
Calibrated Classifier with Adaptive Thresholds

Evaluates fused representations using Platt-calibrated probabilities evaluated against length-bucketed decision boundaries.

✓
Human / AI Classification Verdict

Outputs calibrated probabilities and categorical verdict (Accuracy: 89.88%, ROC-AUC: 95.63%).

🎥

ACTIVE VIDEO PIPELINE: VISION TRANSFORMER (ViT-BASE)

OpenCV YuNet Landmark Alignment + ViT-Base Patch16-224 Multi-Head Attention
1
Temporal Sampling with Safe Seek Bounds

Samples 8 uniform temporal frames across video duration with EOF protection and aspect-ratio validation.

2
YuNet Facial Landmark Detection & Alignment

Extracts facial regions using OpenCV YuNet ONNX detector (score threshold: 0.55, margin: 25%), cropping 224x224 RGB crops.

3
Vision Transformer Patch Multi-Head Attention (12 Heads)

Fine-tuned ViT-Base Patch16-224 divides facial crops into 16x16 non-overlapping patches, computing Multi-Head Attention across blending boundaries.

4
Multi-Crop Temporal Aggregation & Fallbacks

Aggregates frame probabilities. Preserves active fallbacks to V11 EfficientNet-B0, V10 ResNet-18, and V4 Temporal Conv1D with BiGRU attention.

✓
Calibrated Real / Deepfake Verdict

Rule: Real if P(Real) ≥ 47.50%; otherwise Deepfake. Evaluated on Celeb-DF v2 (518 videos, ROC-AUC: 87.18%).

🧠

MULTI-EXPERT ENSEMBLE & SHADOW ROUTING (PHASE 4 ADVANCED PIPELINE)

Selective Domain Routing combining Face ViT + Full-Frame Swin + Temporal ReStraV (DINOv2)
E1
Face ViT Expert (Localized Facial Manipulation)

Specialized in boundary seams, eye/mouth blending artifacts, and warping (active production baseline).

E2
Full-Frame Swin Expert (Spatial Generative Cues)

Evaluates entire RGB frames for diffusion and GAN texture artifacts across faceless and wide-angle scenes.

E3
Temporal ReStraV Expert (Perceptual Straightening Dynamics)

Extracts 21-D temporal curvature features from DINOv2 latent space to detect abnormal diffusion trajectory smoothing.

E4
Validation-Trained Stacking Logistic Regression

Trained strictly on independent 80-video validation data (logit = -4.357 + 3.271·vit + 0.614·face - 0.427·swin + 2.569·restrav).

✓
Shadow-Mode Deployment Contract

Runs concurrently in shadow mode behind ENABLE_ENSEMBLE_ROUTER=0, providing diagnostic transparency without production regressions.

SAFETY & BOUNDARIES

SYSTEM LIMITATIONS & DISCLAIMER

Documented forensic boundaries, error bounds, and responsible use policies.

📄

TEXT DETECTION BOUNDARIES

  • Short Input Ambiguity: Texts under 3 words have insufficient statistical entropy and are classified as Insufficient Evidence.
  • Stylistic Overlap: Formal human technical writing can exhibit low perplexity similar to LLM outputs.
  • Prompt Engineering Shift: Adversarial prompting (burstiness injection) can reduce detection confidence.
  • Language Scope: Primary calibration is optimized for English language corpora.
🎥

VIDEO DETECTION BOUNDARIES

  • Face Detection Requirement: Active ViT requires detectable facial crops. Faceless clips return Insufficient Evidence in production mode.
  • Compression Degradation: Heavy H.264 macroblocking (e.g. 144p mobile rips) can trigger false positives on whole-frame models.
  • Generator Domain Shift: Models trained on face-swap datasets (Celeb-DF) exhibit reduced recall on unseen diffusion engines (Pika).
  • Motion Blur: Rapid camera panning can degrade facial crop resolution below the YuNet threshold.
🛡️

RESPONSIBLE USE POLICY

  • Probabilistic Nature: Detection outputs represent algorithmic likelihoods, not infallible ground-truth certitude.
  • Human-in-the-Loop: Results should assist editorial review and digital forensics, never serve as sole punitive evidence.
  • Safe Shadow Mode: Experimental ensemble models remain gated behind feature flags to prevent unvalidated rollouts.
  • Continuous Auditing: All benchmarks are audited for training overlap to prevent data contamination.
