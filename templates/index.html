PIPELINE SPECIFICATIONS

MODEL ARCHITECTURE

Production inference pipelines used for text and video content analysis.

📄

TEXT DETECTION PIPELINE

Sparse TF-IDF + Dense MiniLM Semantic Fusion (194K+ Features)
1
Input Text Preprocessing

Standardizes encoding, sanitizes tokens, extracts word and character telemetry.

2
Multi-Scale TF-IDF Feature Extraction

Generates Word n-grams (1–3), Char n-grams (3–5), and Subword n-grams (2–6).

3
MiniLM Embeddings & Linguistic Dimensions

Extracts 384-D dense semantic representations alongside 5 scaled stylistic & length metrics.

4
Sparse + Dense Fusion (194,897 Features)

Unifies sparse n-gram spaces and dense semantic embeddings into a single feature vector.

5
Calibrated Classifier & Adaptive Thresholds

Evaluates prediction probabilities using Platt calibration against length-bucketed thresholds.

✓
Human / AI Verdict

Outputs calibrated probability distribution and final categorical verdict.

🎥

VIDEO DEEPFAKE PIPELINE

Spatial ResNet-18 + Temporal Conv1D + BiGRU Multi-Head Attention
1
Video Input & 8 Temporal Frames

Uniformly samples 8 temporal frames across the video duration using OpenCV.

2
YuNet Face Detection & Alignment

Extracts facial regions using the YuNet ONNX detector and normalizes to 224×224 tensors.

3
ResNet-18 Spatial Features (512-dim)

Extracts 512-dimensional spatial representations per facial crop via deep convolutional backbone.

4
Temporal Conv1D & 2-layer BiGRU

Models local inter-frame transitions and bidirectional temporal dynamics across time steps.

5
Multi-Head Attention & Platt Calibration

Self-attention weights suspicious facial micro-manipulations; calibrated against decision threshold.

✓
Real / Fake Verdict

Mapping: 0 = Fake, 1 = Real. Decision: Real if P(Real) ≥ Calibrated Threshold.

SYSTEM OVERVIEW

ABOUT THE SYSTEM

AI Text and Deepfake Detection Using ML is a machine-learning based content verification system designed to analyze written content and video media.

📄

TEXT DETECTION

  • TF-IDF n-grams (Word, Char, Subword)
  • MiniLM embeddings (384-dim dense)
  • Linguistic features (5 stylistic dimensions)
  • Calibrated classification & adaptive thresholding
🎥

VIDEO DETECTION

  • YuNet face detection & alignment
  • ResNet-18 spatial features (512-dim)
  • Temporal Conv1D & 2-layer BiGRU
  • Multi-Head Attention & calibrated decision
⚙️

SYSTEM

  • Text + Video multi-modal analysis
  • 8-frame uniform temporal sampling
  • API-based inference & sub-400ms latency
  • Responsive web interface & local session audit
